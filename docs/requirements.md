# 需求

## 要解决的问题

B 站关注没有分类功能。有的 UP 主只想让算法偶尔刷到，不一定每个视频都看；有的只想大段时间集中看；有的每天更新了就看。需要一个能对 UP 主分类、并展示各分类下未看视频的工具。

## 页面

- **标签视图**：展示各标签下 UP 主的未看视频。
- **UP 主管理**：管理 UP 主（昵称、标签、是否同步），管理其视频的已看/未看/不看状态。
- **同步状态**：手动触发同步，查看上次同步时间与结果。

## 同步状态

- "立即同步"按钮：提交同步任务后立即返回，任务后台执行。
- 进度展示：轮询当前任务进度（已完成/总数、当前 UP 主、新视频数）。
- 历史记录：展示最近一次同步任务的结果。

`SyncTask` 字段：`id` / `scope` / `status` / `started_at` / `finished_at` / `heartbeat_at` / `new_videos_count` / `total_creators` / `completed_creators` / `current_creator_name` / `error_message`。

点击立即同步创建任务，启动两个协程：一个更新，一个心跳（心跳跳的是应用是否 crash）。
